## Caption

> One group. Four ventures. One website.
>
> Billion Dreams Group runs interiors across India and the UAE, an EV charging
> network, a China–UAE–India import line and a software arm. Four very different
> businesses that still had to feel like one company.
>
> So we built one design system that re-skins itself. Interiors wears the group's
> gold. Indish eVolt carries its own green. Nothing in the stylesheet hard-codes a
> colour — one class on the page changes the whole thing. The next venture is a
> six-line change, not a redesign.
>
> And it's quick, because there's nothing in the way: zero JavaScript shipped to
> the browser, one 15 KB stylesheet for the entire site.
