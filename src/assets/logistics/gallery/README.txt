Drop real photos of Billion Dreams Logistics shipments here.

Any .jpg / .jpeg / .png in this folder is picked up automatically by
src/pages/logistics.astro, optimized, and shown in the "On the ground"
grid. No code change needed. Filenames sort alphabetically, so prefix
with numbers (01-, 02-, ...) to control the order.

While this folder holds no images, the section hides itself entirely.

Run `npm run compress` after adding large photos.
